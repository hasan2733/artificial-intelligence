# Foundations Track

## Goal
Build the core data-science and Python fundamentals required before entering ML and DL topics.

## Suggested order
1. Python basics
2. NumPy
3. Pandas
4. Data visualization
5. PyTorch fundamentals
6. Basic optimization concepts

## Main topics
- Variables, loops, functions, classes
- NumPy arrays and vectorization
- DataFrames and preprocessing
- Visualization and exploratory analysis
- Basic PyTorch tensors and operations
- Gradient descent, SGD, and mini-batch training

- `Notebooks/Basic/python_basics.ipynb`
- `Notebooks/Basic/numpy.ipynb`
- `Notebooks/Basic/pandas.ipynb`
- `Notebooks/Basic/matplotlib_and_seaborn_data_visualizing.ipynb`
- `Notebooks/Basic/PyTorch_Basics.ipynb`
- `Notebooks/Basic/gd_VS_sdg_VS_miniBatch .ipynb`

## Learning outcome
By the end of this section, the learner should be able to work with Python, tabular data, charts, and basic tensor operations before moving to ML models.
