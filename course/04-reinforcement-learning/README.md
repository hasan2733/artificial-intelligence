# Reinforcement Learning Track

## Goal
Introduce decision-making, learning from interaction, and RL model paradigms.

## Key concepts
- Agent, environment, state, and action
- Reward signals and policy learning
- Q-learning and DQN
- Temporal difference learning
- RL notebook experiments

- `Notebooks/Reinforcement_Learning/DQN.ipynb`
- `Notebooks/Reinforcement_Learning/Q-Learning.pdf`

## Learning outcome
This section prepares learners to understand how agents improve through feedback and reward rather than supervised labels.
