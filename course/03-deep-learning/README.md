# Deep Learning Track

## Goal
Learn neural networks, CNNs, sequence modeling, and modern transformer concepts.

## Suggested order
1. Artificial neural networks foundations
2. Single-layer perceptron and neural basics
3. CNNs and data augmentation
4. Transfer learning and pretrained models
5. RNN and LSTM
6. Transformer architecture
7. Accuracy and evaluation metrics

## Main topics
- ANN basics
- Perceptron and hidden layers
- CNN image classification
- Object detection
- Transfer learning
- Sequence models
- Metrics like confusion matrix and accuracy
