# Course roadmap

This branch is organized into a learning-platform style flow:

- Foundations: Python, data science, and tensor basics
- Machine learning: classical algorithms and evaluation
- Deep learning: ANN, CNN, RNN, and transformers
- Reinforcement learning: decision-making and reward-based learning
- Capstone projects: applied, end-to-end AI experiments

## Original source material
The original repo contents remain the source material for all of the above topics. This structure simply improves readability and learning flow.
