# Machine Learning Track

## Goal
Study classic machine learning algorithms and model evaluation processes.

## Suggested order
1. Linear regression
2. Logistic regression
3. KNN
4. Naive Bayes
5. SVM
6. Decision trees and random forest
7. K-means clustering
8. Cross-validation and evaluation

## Main topics
- Supervised learning
- Unsupervised learning
- Feature engineering and evaluation
- Regression and classification
- Model comparison and validation
- Clustering and similarity metrics
