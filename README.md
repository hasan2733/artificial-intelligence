# Artificial Intelligence Learning Path

This branch reorganizes the original repository into a clearer course-style structure while preserving the original notebook-driven learning flow.

## Repository purpose
This repository is a personal AI learning repository covering:
- Python and data science foundations
- Machine learning fundamentals
- Deep learning and neural networks
- CNN, RNN, transformers, and transfer learning
- Reinforcement learning
- Practical implementation projects

## Learning flow

1. Start with Foundations
2. Move to Machine Learning
3. Progress into Deep Learning
4. Learn Reinforcement Learning
5. Finish with capstone / implementation projects
6. Use notes, datasets, and research documents as supporting material

## Original source content
The original repository content was kept as the source of truth for the learning material. This branch is a cleaner, structured presentation of the same study path for easier navigation.

## Recommended study order

- Python basics
- NumPy and Pandas
- Visualization
- Linear and logistic regression
- Decision trees, SVM, KNN, naive Bayes
- Cross-validation and evaluation
- ANN fundamentals
- CNNs and transfer learning
- RNN and LSTM
- Transformers
- Reinforcement learning
- End-to-end AI projects
